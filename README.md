# DangerousSpacePlugin

A plugin (Mod) for Risk of Rain 2, made by the DSS for the DSS.   
Contributions are welcome, talk to Kyle for instruction on how to contribute.

## Development Setup and Building
See [this guide](https://risk-of-thunder.github.io/R2Wiki/Mod-Creation/Getting-Started/First-Mod/#r2api) for instructions on developing and building mods, but use this repo's files instead of the ones mentioned in the guide.   
Optionally, you can also copy `Thunderstore/DangerousSpacePlugin/DangerousSpacePlugin.language` into your BepinEx plugins directory. If you don't do this, the mod's text will not load, but the mod will be otherwise playable.
