# DangerousSpacePlugin

A plugin (Mod) for Risk of Rain 2, made by the DSS for the DSS.   
Contributions are welcome, talk to Kyle for instruction on how to contribute.

## Development Setup and Building
See [this guide](https://risk-of-thunder.github.io/R2Wiki/Mod-Creation/Getting-Started/First-Mod/#r2api) for instructions on developing and building mods, but use this repo's files instead of the ones mentioned in the guide.   
Optionally, you can also copy `Thunderstore/DangerousSpacePlugin/DangerousSpacePlugin.language` into your BepinEx plugins directory. If you don't do this, the mod's text will not load, but the mod will be otherwise playable.

## Contributing

If you'd like to contribute:
-  If you want to help but you don't know what to do, ask Kyle. In the future, you'll be able to check the Issues page to find problems to tackle.
-  If you have a vague idea for something to add to the mod, send it in the Discord thread.
-  If you have a concrete suggestion for changes or additions to the mod, create an Issue on this repo.
-  If you find a bug in the mod, create an Issue on this repo explaining the bug. If you can, include instructions on how to reproduce the issue in game.
-  If you want to add code, submit a Pull Request to this repo with the code.
-  If you want to add assets, Pull Requests are encouraged, but sending them directly to Kyle is fine as well.
